# GDriveTree 归档入树：按名称匹配云端子项时的容错

## Goal

修复归档记录入树反复失败：`云端未找到路径段`。

现象（用户日志）：

```
归档记录 2970 入树失败：按文件 ID 1rgnZf... 解析失败：归档目标不在当前目录树根目录下；
按路径 /媒体库/电视剧/日漫/明天，美食广场见。 (2025)/Season 1/明天，美食广场见。.2025.S01E02.第2集.mkv
解析失败：云端未找到路径段：/媒体库/电视剧/日漫/明天，美食广场见。 (2025)/Season 1/
```

只有最后一段（文件名）失败，父目录段全部解析成功。

## Background / Confirmed Facts

- 归档入树走 `_ensure_nodes_for_path()`：逐段先在本地 `tree_node` 查路径，
  缺失时用 `client.find_child(parent_id, segment)` 向云端按名称精确查询
  （`plugins.v3/gdrivetree/__init__.py:1187`）。
- `find_child()` 的 Drive 查询是 `'<parent>' in parents and name = '<name>'`，
  只转义 `\` 与 `'`（`plugins.v3/gdrivetree/gdrive_tree_client.py:326`、`:356`）。
- 精确查询失败即抛 `云端未找到路径段`，没有容错回退。
- 按文件 ID 兜底失败的原因是「父链不在配置根下」（快捷方式目录），
  属已有设计行为，不是本次要改的点。
- 用户怀疑是空格或全角符号导致；实际现象显示父目录（含全角逗号、全角句号、
  空格、括号）都能匹配，因此差异集中在文件名本身。

## Confirmed Root Cause (待实现验证)

`name = '...'` 是大小写敏感、字符级精确匹配。任何一侧的差异都会导致查不到：

1. Unicode 全角/半角差异（`，` U+FF0C vs `,`、`。` vs `.`、全角括号/字母）；
2. 首尾空白或连续空格差异；
3. 零宽字符（U+200B/U+FEFF）或不换行空格 U+00A0；
4. 宿主/命名模板对名字做过规范化，而归档历史保留原文。

## Requirements

### R1 精确查询失败后的容错匹配

- 在按名称查询云端子项时，精确查询失败后回退为「列出该目录子项 + 归一化比较」。
- 归一化分层，按优先级依次尝试，且每层必须**唯一命中**才采用：
  1. 原样相等；
  2. Unicode NFKC（全角/半角、兼容字符）+ CJK 标点映射（`。`→`.`、`、`→`,`）
     + casefold + 去除零宽字符 + 首尾空白裁剪 + 内部连续空白折叠为单空格
     （处理全角/半角标点、大小写、空白数量差异）；
  3. 第 2 层再去掉全部空白（处理空格有无的差异）。
- 某一层出现多个候选时，视为有歧义，不猜，报错并列出候选名。
- 回退比较只用于定位，最终写入树的名字仍以**云端返回的真实名称**为准。

### R2 可观测性

- 容错命中时输出 INFO 日志：`历史名 -> 云端名`（附命中的归一化层级）。
- 仍然匹配不到时，错误信息附上该目录下最多 5 个候选名，便于下次直接判断差异类型。
- 子项列举失败（权限/网络）不影响原有错误信息，追加说明即可。

### R3 不改动既有语义

- 精确查询成功时行为、日志、请求数完全不变（不额外调用列举接口）。
- 不改变 `_relative_path_segments`、`_nodes_from_metadata`、`_upsert_nodes` 的逻辑。
- 不改变归档记录的状态机（`done` / `failed` / 重试次数）。
- 不新增配置项、不新增数据库表或列。

### R4 测试

- 纯模块测试：归一化层级、唯一命中、歧义拒绝、零宽字符。
- 客户端测试：`list_children` 分页与字段请求。
- 运行时测试：全角差异/空格差异能入树；歧义时报错含候选名；
  精确命中时不触发列举接口（可用替身计数断言）。

## Acceptance Criteria

- [ ] 云端名为 `明天，美食广场见。.2025.S01E02.第2集.mkv`，归档路径中的名字
      使用半角逗号/句号时，能通过第 2 层归一化匹配并成功入树，
      写入树的名字为云端真实名称。
- [ ] 名字仅多/少空格时能通过第 3 层匹配。
- [ ] 同一目录下有两个候选仅在第 2 层归一化后相同（如 `A。mkv` 与 `A.mkv`）时，
      不自动选择，抛错且错误信息包含这两个候选。
- [ ] 完全匹配时 `list_children` 不被调用。
- [ ] 匹配不到时错误信息包含候选名（有子项时）。
- [ ] 现有 `tests/v3/gdrivetree` 全部通过。
- [ ] `python -m py_compile` 通过，`package.v3.json` 版本与 history 一致。

## Out of Scope

- 不处理「父链不在根下」的快捷方式 ID 解析（已有设计，另有兜底路径）。
- 不做模糊字符串相似度（编辑距离）匹配，避免误配。
- 不重命名云端文件，不修改归档历史。
- 不刷新整棵目录树。
