# 谷歌 STRM 管理（GDriveStrm）

读取 [Google Drive 目录树](../gdrivetree/) 插件持久化的目录树，把视频文件按原父子结构
映射为本地 `.strm` 文件，供 Emby/Jellyfin 等媒体服务器识别。

## 功能

- **结构一致**：树中 `/A/B/C/D/a.mkv` 映射为 `<输出根>/A/B/C/D/a.strm`；
  只创建命中视频文件的目录链。
- **直链内容**：`.strm` 内写入
  `https://www.googleapis.com/drive/v3/files/{fileId}?alt=media&supportsAllDrives=true`；
  文件快捷方式优先使用目标文件 ID。
- **后缀白名单**：默认覆盖常见视频格式（mkv/mp4/avi/ts/m2ts/iso/rmvb…），可自定义。
- **事件增量**：GDriveTree 开启「通知 STRM 插件」后，树变化会定向发送
  `tree.changed` 事件，本插件合并后秒级写入。
- **定时同步**：按间隔对账，补齐漏掉的 STRM。
- **全量同步**：逐文件校验内容并重写不一致项，清理失效记录。
- **安全清理**：只删除本插件记录过且源节点已消失的 `.strm`，并回收空目录；
  用户自行放入的文件不会被删除。
- **幂等写入**：内容一致不重写，不改变文件修改时间。

## 前置条件

1. MoviePilot V3（`>= 3.0.0`）。
2. 已安装并启用 **GDriveTree**，且至少成功刷新过一次目录树。
3. 输出根目录在容器内可写。默认 `/config/strm`，建议映射到媒体库所在目录。

## 配置项

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 启用插件 | 关 | 插件总开关 |
| 目录树插件 ID | `GDriveTree` | 使用插件分身时填分身 ID |
| STRM 输出根目录 | `/config/strm` | 绝对路径；相对路径按宿主配置目录解析 |
| 视频后缀 | 常见视频格式 | 逗号/空格/换行分隔；留空恢复默认 |
| STRM 内容模板 | Google Drive 直链 | 必须包含 `{fileId}` |
| 处理目录树事件 | 开 | 是否响应 `tree.changed` |
| 清理失效 STRM | 开 | 删除源已消失的已记录文件 |
| 定时同步 | 关 | 注册 interval 定时任务 |
| 同步间隔（分钟） | 10 | 1–1440 |
| 每页记录数 | 20 | 详情页分页大小 |

## 同步方式

| 方式 | 触发 | 行为 |
| --- | --- | --- |
| 事件增量 | GDriveTree 的 `tree.changed` | 只处理事件中的新增/更新/删除节点 |
| 定时同步 | 定时任务 | 读取整棵树，按记录差量补齐 |
| 立即同步 | 详情页按钮 | 同定时同步，手动立即执行 |
| 全量同步 | 详情页按钮 | 读取整棵树并逐文件校验内容 |

事件、定时和按钮都只入队，由单个后台线程串行执行；短时间内的多次事件会合并，
超过 5000 个变更节点时自动升级为整树对账。

事件载荷来自 GDriveTree：

```json
{
  "plugin_id": "GDriveTree",
  "event_name": "tree.changed",
  "data": {
    "kind": "refresh",
    "full": false,
    "added": [{"file_id": "...", "path": "/A/a.mkv", "name": "a.mkv", "is_dir": false}],
    "updated": [],
    "removed": [{"file_id": "...", "path": "/A/old.mkv"}]
  },
  "__mp_target_plugin_id": "GDriveStrm"
}
```

`full = true`（整体替换、清空或变更过多）表示本插件应按整树重新对账。

## 数据表

- `strm_record`：已写出的 STRM 记录（`rel_path` 唯一，`source_file_id` 索引）。
- `strm_meta`：单行（`id=1`）保存同步状态、统计与错误。

记录只用于差量和清理，目录树数据库始终是事实来源；记录丢失时会读文件内容兜底。

## API

| 路径 | 参数 | 说明 |
| --- | --- | --- |
| `/sync` | 无 | 入队增量对账 |
| `/sync/full` | 无 | 入队全量同步 |
| `/status` | 无 | 状态、统计与树源可用性 |
| `/records/page` | `{"page": 1}` | STRM 记录分页 |
| `/clear` | 无 | 清空记录与统计（不删磁盘文件） |

所有接口返回恰好三键 `{success, message, data}`。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 目录树尚未构建 | 先在 GDriveTree 执行一次刷新 |
| 读取目录树失败 | 确认目录树插件 ID 正确、插件已启用、数据库可用 |
| 输出目录无效或不可写 | 检查路径是否为绝对路径、容器内是否有写权限 |
| 路径中没有出现预期的层级 | 检查 GDriveTree 的 `root_path`；相对路径已去掉该前缀 |
| Emby/Jellyfin 无法播放 | 直链需要 Google OAuth；请配合可携带授权的代理或网关使用 |
| 删除/改名后旧 STRM 仍在 | 确认「清理失效 STRM」已开启；或执行一次全量同步 |
| 切换输出目录后旧目录文件还在 | 切换时插件会重置记录并跳过首次清理，旧目录文件需手动处理 |
| 多个实例共用同一输出目录 | 不要同时开启清理，或为每个实例使用不同输出目录 |
| 定时同步也补齐不了 | 检查事件/定时开关，并查看详情页最近错误 |

## 说明

- 本插件只读 GDriveTree 的数据，不访问 Google Drive 接口、不修改云端文件。
- 不做转码、不生成 nfo/封面/字幕，不代理视频流。
- 首版为单目录树、单输出根目录。
- Google Drive 允许同目录同名文件；同一路径只会生成一个 STRM（按路径与文件 ID
  排序取最后一个）。
